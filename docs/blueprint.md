# **App Name**: BPMN FlowForge

## Core Features:

- Process Step Input: Accept user input of process steps as a list, allowing each step to be on a new line or comma separated.
- Smart BPMN Generation: Generate BPMN XML code based on the list of process steps, automatically creating tasks and gateways (for steps containing questions).
- XML Output Display: Display the generated BPMN XML code in a text area.
- XML Copy to Clipboard: Allow the user to copy the generated XML code to the clipboard.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082), providing a sense of depth and focus.
- Background color: Light gray (#F0F0F0), offering a clean and neutral backdrop.
- Accent color: Lavender (#E6E6FA), to highlight interactive elements and draw attention.
- Body and headline font: 'Inter' for a modern, machined and objective look; good for both headlines and body text.
- Code font: 'Source Code Pro' for displaying XML code snippets.
- Use simple, geometric icons for UI elements, ensuring they are consistent and easy to understand.
- Divide the screen into two main sections: one for input and one for output. Maintain a clean and spacious layout with consistent padding.
