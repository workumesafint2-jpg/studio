## GitHub Token (Password) አጠቃቀምና የ 403 Error መፍትሄ
ኮድ በ GitHub በኩል ስትልክ (Push ስታደርግ) "403 Error" ወይም "Write access not granted" ካለህ የሚከተሉትን ደረጃዎች ተከተል፦

1. **አዲስ Token ፍጠር**: GitHub ገጽህ ላይ ሂድ -> **Settings** -> **Developer settings** -> **Personal access tokens** -> **Tokens (classic)**።
2. **ስልጣን ስጠው**: **Generate new token (classic)** ተጫን። ለቶክኑ ስም ስጠው (ለምሳሌ: `worku-token`)። **በጣም አስፈላጊ**: `repo` የሚለውን ሳጥን (Checkbox) አብራው። 
3. **Token ኮፒ አድርግ**: ኮዱን (ለምሳሌ: `ghp_...`) ኮፒ አድርገህ ያዘው።
4. **Terminal ላይ ተጠቀም**: ሲስተሙ ላይ `git push` ስታደርግ Username ሲጠይቅህ የ GitHub ስምህን፣ Password ሲጠይቅህ **አዲሱን Token (ኮድ)** አስገባ።
